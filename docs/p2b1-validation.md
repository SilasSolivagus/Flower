## 4. 人工验收清单（供用户试用）

用自己的账号登录 `pnpm dev` 启动的开发环境逐项打勾；发现的问题记在本节末尾。可以直接使用控制方留在 pan123 的复验数据：需求 **PAN-765**、PRD **PAN-PRD-204**（也可以自己新建，新建的测试数据用「验收-」开头命名，结束后删除或改回）。

`[[` 补全与选小节
- [ ] 需求描述编辑框里输入 `[[`，出现补全列表；按编号（如 `PAN-7`）和按标题关键词都能搜到目标。
- [ ] 补全里选一份 PRD 后，继续输入 `#` 或文字，能从该 PRD 的小节列表里选一节；保存后描述里出现 `[[PAN-PRD-n#小节标题]]`。
- [ ] PRD 正文编辑器里输入 `[[`，同样弹出补全并能选小节（用真实键盘，不要用鼠标粘贴）。
- [ ] 评论输入框里同样能触发 `[[` 补全。

链接卡
- [ ] 保存后的链接卡显示目标当前的编号、标题与状态；点击能跳转到对应页面，指向 PRD 小节的链接会把该小节滚动到页面顶部。
- [ ] 链接卡下方有一行灰色说明：找不到目标、目标已删除、目标已取消、或小节已失效时分别显示对应文字，且不可点击。
- [ ] 把被引用的需求标题、或被引用的迭代名称改掉，再刷新含链接的页面，确认链接卡没有变灰、仍指向同一个目标（链接按 id 存储，不随编号或名称变化而断开）。
- [ ] 把一份 PRD 里被链接的小节标题改掉或删掉该节，保存后回到引用处，确认链接卡显示「小节已失效」。
- [ ] 用一个看不到目标所在产品的账号查看含链接的页面，确认链接卡只显示目标编号，不显示标题、状态，不可点击。

被引用
- [ ] 需求、PRD、任务、迭代详情页都能看到「被引用」区块，列出引用它的来源、上下文摘要与时间。

任务编号与任务详情
- [ ] 甘特表里的任务显示 `{产品编号}-T-n` 形式的编号；点击能进入只读的任务详情页，显示编号、标题、状态、负责人、工期、进度、所属需求与迭代。

评论锚点与联动
- [ ] 在 PRD 正文里选中一段文字添加评论，确认该段文字在编辑器里被高亮；点击高亮能让评论区滚动到对应评论并标出；评论区里点击该条评论，编辑器内的高亮加深。

工作台未读评论
- [ ] 作为某份 PRD 的负责人或曾在该 PRD 上评论过的人，有新的未读评论时，工作台「未读评论」里出现该 PRD 的链接与未读条数；点开 PRD 后该条从列表消失。
