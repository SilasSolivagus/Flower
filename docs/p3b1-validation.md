## 5. 人工验收清单（供用户试用）

1. 评论、需求描述、PRD 正文里输入 `@`：补全按姓名或邮箱筛选；看不到该产品的成员标「看不到这个产品」；发表或保存后显示成员标签。
2. 顶栏铃铛：未读数、「全部 / 未读 / @我」、点击跳转并标为已读、全部标为已读；通知页的筛选与加载更多。
3. 被指派（需求负责人、新增分配、任务指派、PRD 负责人）、关注与取消关注、等我签字。
4. 个人设置 → 通知：各类通知的站内、企业微信、邮件开关。
5. 组织设置 → 成员：手动填写企业微信账号；用 CSV（邮箱, 企业微信账号）预览并导入。
6. 组织设置 → 推送 → 企业微信应用；个人通知邮件通道。
7. 产品设置 → 推送：个人提醒通道。

## 6. 正式部署后要做的事

1. 在企业微信自建应用里配置授权回调域，在推送页填写企业 ID、应用 ID、应用密钥并开启扫码绑定，用真实扫码验证绑定。
2. 决定是否为上线前已有的负责人、评论者补自动关注（P3-B1 不补，只从上线后开始）。
3. 为需要企业微信个人提醒的产品指定个人提醒通道，为成员填写或导入企业微信账号。
