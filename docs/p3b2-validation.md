## 5. 已知的数据限制

- **版本按期达成率**：pan123 的版本没有计划日期、基线日期与所属迭代，按期达成率为「暂无数据」。补救办法是为历史版本补计划日期或关联迭代，由用户决定。
- **评审效率与驳回率**：迁移来的评审记录不是 `check_item.*` 事件，这两项从上线后开始统计。
- **迭代承诺完成率**：迁移来的迭代没有承诺范围快照，之后在 Flower 里开始的迭代会有快照。
- **专项**：已完成的那个专项，完成率为 0%（0 / 8），因为它的需求目前都不在完成类状态。这是数据现状，与 SQL 一致。
