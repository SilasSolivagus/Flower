## 4. 人工验收清单（供用户试用）

用自己的账号登录 `pnpm dev` 启动的开发环境逐项打勾；发现的问题记在本节末尾。可以直接使用控制方留在 pan123 的复验数据：业务域「P2-B2 复验」、测试 PRD **PAN-PRD-205**、模块文档 **PAN-PRD-206**（也可以自己新建，新建的测试数据用「验收-」开头命名，结束后删除或改回）。

模块文档页签与新建
- [ ] 「模块文档」页签按业务域列出结构树里的模块；还没有文档的模块显示「还没有模块」；点开该模块即新建一份模块文档。
- [ ] 只读成员看不到新建入口；点开已有模块文档可以正常查看。

模块文档编辑与归档
- [ ] 模块文档使用与变更 PRD 相同的编辑器，支持自动保存、修订列表、按小节对比与恢复、`[[ ]]` 链接、评论。
- [ ] 把模块文档状态改为归档后，编辑器变为只读，「恢复」按钮消失；改回使用中后恢复可编辑；归档不影响所属模块本身。

影响声明与当场新建节点
- [ ] 在一份评审中/已通过/已上线之前的 PRD 侧栏「影响的功能点」里新增声明：可以选择已有模块与功能点，也可以当场新建模块或功能点（产品编辑权限即可，不需要产品管理员）。
- [ ] 每条声明可选变更类型（新增 / 修改 / 删除）；修改类可选来源小节；声明可以编辑、移除后再加回。
- [ ] PRD 进入已合入状态后，声明不能再增删改（锁定）。

来源小节失效提示
- [ ] 声明选了来源小节后，把 PRD 正文里对应的小节标题改掉或删除，回到声明处确认提示「来源小节已失效」。
- [ ] 已废弃的功能点不能被新声明选中；已有的旧声明仍可正常编辑和合入。

合入页的应用 / 跳过 / 撤销 / 版本冲突
- [ ] PRD 上线后侧栏出现「合入模块文档」入口，按模块分组列出全部声明。
- [ ] 「新增/修改」声明的右侧预填来源小节内容（找不到来源或未选来源时为空），可编辑后应用；应用后模块文档按声明类型替换、按顺序插入或删除对应小节，并生成一条带来源的修订。
- [ ] 跳过某条声明后若所有声明都已处理完，PRD 变为「已合入」；撤销最后一条跳过会让 PRD 退回「已上线」，再次处理完会重新变为「已合入」。已应用的声明不能撤销（通过模块文档的修订记录手动恢复）。
- [ ] 应用时模块文档在另一处被改动造成版本冲突，页面提示刷新重试。
- [ ] 没有声明的 PRD、或已作废的 PRD 不显示合入入口。

PRD 变为已合入与「PRD」检查项
- [ ] 全部声明处理完后 PRD 状态变为「已合入」，文档列表的状态筛选里能按「已合入」筛选；需求上的「PRD」检查项随之同步为通过。

修订来源与合入记录
- [ ] 模块文档的修订列表里，合入产生的修订显示「合入 {PRD编号}：…」并带指向来源 PRD 的链接。
- [ ] 模块文档有「合入记录」区块，列出历次合入的来源 PRD 与时间。

功能点改名同步
- [ ] 在结构树页签把某个功能点改名，对应模块文档里该功能点的小节标题同步更新，并生成一条「功能点改名：旧名 → 新名」的修订。

节点链接跳到模块文档小节
- [ ] 在 PRD 正文或评论里写 `[[业务域/模块/功能点]]`，保存后点击链接卡跳到该模块的模块文档并滚动到对应小节；`[[业务域/模块]]` 跳到模块文档本身；模块或功能点还没有文档时链接卡指向「模块文档」页签。

结构树页签的模块文档链接
- [ ] 结构树页签里已有模块文档的模块行显示该文档的编号链接，点击跳转到模块文档。
